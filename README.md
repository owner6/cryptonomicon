# Cryptonomicon

Веб-додаток для відстеження курсів криптовалют у доларах США. Додайте тикери (наприклад, BTC, ETH, DOGE), переглядайте актуальні ціни на картках і будуйте простий графік історії для обраної монети.

Назва — від [«Криптономікон»](https://uk.wikipedia.org/wiki/Криптономікон) Ніла Стівенсона; за задумом це легкий «рабочий стіл» для швидкого огляду ринку, а не повноцінна біржа чи портфель.

## Можливості

- **Список тикерів** — введення символу та додавання в список відстеження.
- **Ціни в USD** — оновлення через [CryptoCompare API](https://min-api.cryptocompare.com/) (інтервал опитування ~5 с).
- **Картки** — для кожного тикера відображаються назва та поточна ціна.
- **Видалення** — прибрати тикер зі списку одним кліком.
- **Міні-графік** — після вибору картки накопичується історія цін і показується стовпчикова діаграма (нормалізація висоти стовпців відносно min/max у вибірці).

## Стек

| Частина | Технологія |
|--------|------------|
| UI | [Vue 3](https://vuejs.org/) (Options API, один кореневий компонент) |
| Збірка | [Vue CLI](https://cli.vuejs.org/) (`vue-cli-service`), у проєкті також є [Vite](https://vitejs.dev/) |
| Стилі | Utility-класи (Tailwind-подібна розмітка в `App.vue`, глобальні стилі в `src/app.css`) |
| Дані | REST CryptoCompare (`/data/price`) |

## Вимоги

- [Node.js](https://nodejs.org/) (рекомендовано LTS)
- npm

## Встановлення та запуск

```bash
npm install
```

Режим розробки (hot reload):

```bash
npm run serve
```

Збірка для продакшену:

```bash
npm run build
```

Перевірка стилю коду:

```bash
npm run lint
```

Після `npm run serve` відкрийте URL з консолі (зазвичай `http://localhost:8080`).

## API-ключ

Запити до CryptoCompare використовують параметр `api_key`. Для локальної розробки отримайте ключ на [cryptocompare.com](https://www.cryptocompare.com/) і підставте його в запит у `src/App.vue` (або винесіть у змінну середовища — зараз ключ захардкоджений у коді).

**Не комітьте** робочі секрети в публічний репозиторій.

## Стан проєкту

Версія **0.1.0** — навчальний / початковий прототип. Частина UI (швидкий вибір тикерів, перевірка дублікатів) ще не підключена до логіки; інтервали опитування не очищаються при видаленні тикера — це варто врахувати при подальшій розробці.
